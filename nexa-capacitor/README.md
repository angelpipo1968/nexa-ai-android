# Nexa AI — Android APK Wrapper

Android app that wraps the live Nexa AI web app at `http://192.168.50.158:3000` in a native WebView using [Capacitor](https://capacitorjs.com/).

## What this is

A lightweight APK (~3–5 MB) that opens directly to your live Nexa AI server. The Android app gives you:

- Native launcher icon + splash screen
- Microphone permission (for hands-free voice mode)
- Camera permission (for the "+" menu camera option)
- Storage permission (for file uploads)
- HTTP cleartext access to your local network server (192.168.50.158:3000)
- Status bar + back button integration
- Adjustable viewport on keyboard show

## How to build the APK

### Option 1 — GitHub Actions (recommended, no Android Studio needed)

1. Push this repo to GitHub: `https://github.com/angelpipo1968/nexa-ai-android.git`
2. Go to the **Actions** tab in your repo on GitHub.com
3. Click **"Build Android APK"** → **"Run workflow"** → **"Run workflow"**
4. Wait ~5 minutes
5. Click the run → scroll to **Artifacts** → download `nexa-ai-debug-apk`
6. Unzip → install `app-debug.apk` on your Android phone

### Option 2 — Local build with Android Studio

1. Install [Android Studio](https://developer.android.com/studio) on your PC
2. Clone this repo:
   ```bash
   git clone https://github.com/angelpipo1968/nexa-ai-android.git
   cd nexa-ai-android
   ```
3. Install Capacitor deps:
   ```bash
   npm install
   ```
4. Sync the web assets to the native project:
   ```bash
   npx cap sync android
   ```
5. Open the `android/` folder in Android Studio
6. **Build → Build Bundle(s) / APK(s) → Build APK(s)**
7. The APK will be at `android/app/build/outputs/apk/debug/app-debug.apk`

## Install the APK on your phone

1. Transfer the `app-debug.apk` to your Android phone (USB, email, Drive, etc.)
2. On the phone, open the file
3. Allow "Install from unknown sources" if asked
4. Tap **Install**

## Important — network requirement

The app points to `http://192.168.50.158:3000`. For the app to work, your phone must be:

- Connected to the **same WiFi network** as your server (192.168.50.158)
- Able to reach `192.168.50.158:3000` (no firewall blocking port 3000)

If you change the server IP or port, edit `capacitor.config.json` → `server.url`, commit, and rebuild.

## Customization

### Change the server URL

Edit `capacitor.config.json`:

```json
"server": {
  "url": "http://YOUR_SERVER_IP:PORT",
  "cleartext": true
}
```

Also update `android/app/src/main/res/xml/network_security_config.xml` to allow your new IP/domain.

### Change the app icon

Replace the vector drawable at:
```
android/app/src/main/res/drawable/ic_launcher_foreground.xml
```

### Change the app name

Edit `android/app/src/main/res/values/strings.xml`:
```xml
<string name="app_name">Nexa AI</string>
```

## Tech stack

- **Capacitor 6** — native runtime bridge
- **Android Gradle Plugin 8.5** + **Gradle 8.7**
- **compileSdk 34**, **minSdk 23** (Android 6.0+), **targetSdk 34**
- **Java 17**
- No native plugins — pure WebView wrapper for fast build

## Troubleshooting

**APK won't install on phone**
→ Make sure you enabled "Install unknown apps" for your file manager in Settings → Apps.

**App shows blank screen**
→ Your phone is not on the same WiFi as the server. Connect to the same network.

**Microphone doesn't work**
→ Go to Settings → Apps → Nexa AI → Permissions → Microphone → Allow.

**"Network connection error"**
→ Make sure your server at `192.168.50.158:3000` is running. Test from a laptop browser on the same WiFi first.

**Build fails on GitHub Actions**
→ Check the Actions logs. Most common issue: Gradle couldn't download a dependency (transient network issue) — just re-run the workflow.
