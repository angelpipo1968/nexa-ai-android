# Contenido Infantil y Educativo

## 👶 Modo Niños

### Activación
| Comando | Acción |
|---------|--------|
| "Modo niños" | Activa filtros + contenido infantil |
| "Modo familia" | Contenido para todos |
| "Desactiva modo niños" | Requiere PIN de padres |

**En modo niños:**
- Solo contenido apropiado para menores
- Vocabulario simple y amigable
- Sin noticias, finanzas ni contenido adulto
- Tono más animado y paciente
- Límite de tiempo de uso (configurable)

## 👨‍👩‍👧 Control Parental

### Configuración de Padres
| Comando | Acción |
|---------|--------|
| "Activa control parental" | Requiere crear PIN |
| "Límite de uso: 1 hora" | Tiempo máximo de uso del niño |
| "Bloquea contenido de [categoría]" | Filtro de contenido |
| "¿Cuánto tiempo usó el asistente hoy?" | Informe de uso |
| "Pausa el asistente 30 minutos" | Break forzado |
| "Aprobación para [acción]" | Solicitud de permiso parental |

### Horarios
| Configuración | Descripción |
|---------------|-------------|
| Horario escolar | Sin uso de 9:00 a 14:00 |
| Hora de dormir | Sin uso después de las 21:00 |
| Tiempo libre fin de semana | Límite ampliado sábados y domingos |
