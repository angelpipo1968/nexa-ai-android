## 🎯 Trivia y Quiz

### Modos de Juego

**Trivia Rápida:**
> "¿Cuántos huesos tiene el cuerpo humano?" → Espera respuesta → Puntúa

**Quiz por Categorías:**
- Geografía, Historia, Ciencia, Arte, Música, Cine, Deporte, Videojuegos, Literatura, Tecnología

**Comandos de trivia:**
| Comando | Acción |
|---------|--------|
| "Juguemos a trivia" | Inicia sesión de 10 preguntas |
| "Trivia de [categoría]" | Trivia temática |
| "Pregunta difícil" | Nivel hard |
| "Pregunta fácil" | Nivel easy |
| "¿Cuál era la respuesta?" | Revela respuesta sin puntuar |
| "Puntuación" | Muestra score actual |
| "Termina el juego" | Fin + resumen de puntuación |
| "Siguiente pregunta" | Pasa sin responder |
| "Juega tú solo" | Modo demostración |

**Formato de pregunta:**
```
❓ Pregunta [N]/10 — [Categoría] — [Dificultad]
[Texto de la pregunta]
```

**Al responder correctamente:** "✅ ¡Correcto! +1 punto."
**Al responder mal:** "❌ Incorrecto. La respuesta era [X]. +0 puntos."

## 🎮 Juegos de Palabras

### 20 Preguntas
> "Juguemos a 20 preguntas"
- Nexa piensa en un concepto
- Usuario hace hasta 20 preguntas de sí/no
- Nexa responde "Sí", "No", "A veces" o "Depende"
- Si adivina antes del 20: Usuario gana
- Variante: el usuario piensa y Nexa hace preguntas

### Adivina el Personaje
> "Adivina el personaje famoso"
- Nexa da pistas una por una
- Usuario adivina con los menos pistas posible
- Puntuación: 5 pistas = 1 punto, 1 pista = 5 puntos

### El Ahorcado
> "Juguemos al ahorcado"
- Nexa elige una palabra
- Usuario dice letras
- Representación textual del ahorcado: `_ _ _ _ _ [A] [E]`
- Vidas: 6 intentos

### Trabalenguas
> "Dime un trabalenguas"
- Trabalenguas en español
- Variante: "Repite este trabalenguas más rápido que yo"

### Rima / Completar la Frase
> "Completa la frase: En un lugar de la Mancha..."
> "Dime una palabra que rime con 'amor'"

## 📖 Cuentos e Historias

### Cuentos
| Comando | Acción |
|---------|--------|
| "Cuéntame un cuento" | Historia corta aleatoria |
| "Cuento de princesas" | Temático |
| "Cuento de terror" | Horror suave |
| "Cuento de ciencia ficción" | Sci-fi |
| "Cuento para dormir" | Tranquilo, ritmo lento |
| "Un cuento de 2 minutos" | Muy corto |
| "Cuento interactivo" | Elige tu aventura |
| "Continúa el cuento" | Sigue desde donde lo dejó |

**Cuento Interactivo (Elige tu aventura):**
```
[Narracion]...
¿Qué hace [personaje]?
A) [Opción 1]
B) [Opción 2]
C) [Opción 3]
```
Usuario dice "A", "B" o "C" → la historia continúa según la elección.

## 🧠 Juegos de Lógica y Acertijos

### Acertijos
| Comando | Tipo |
|---------|------|
| "Dime un acertijo" | Acertijo clásico |
| "Acertijo de lógica" | Puzzle de deducción |
| "Adivinanza" | Descripción poética de objeto |
| "Acertijo matemático" | Número o álgebra |
| "Acertijo visual" | Describido en texto |

**Formato:**
1. Presenta el acertijo
2. Espera respuesta (o pistas si el usuario pide)
3. Revela solución si pide

### Pistas Disponibles
> "Dame una pista" → Revela una pista sin spoilear la solución
> "Me rindo" / "No sé" → Revela la respuesta
